# GitSync --- Privacy Policy

**Effective date:** October 16, 2026\
**App:** GitSync for Android\
**Contact:** khansuhail786098@gmail.com

GitSync helps you connect to GitHub from your Android device, create
repositories, and upload individual files or project folders to
repositories you choose.

This Privacy Policy explains what information GitSync handles, why it is
used, and the choices available to you. Please read it before using the
app.

## 1. Information GitSync Handles

### GitHub account and authentication information

When you connect GitHub, GitSync uses GitHub's authentication process
(GitHub App Device Flow) to authorize actions you request. This may
involve your GitHub username or account details made available by
GitHub, an authorization token, and repository information needed to
perform the requested action.

GitSync uses the authorization granted by you to access GitHub features
required by the app. Your GitHub password is entered on GitHub's own
website, not into GitSync.

### Files and folders you choose

When you select files or a project folder, GitSync accesses the selected
content to carry out the upload or sync you request. The files may
contain source code, documents, configuration files, or other content
you have chosen.

**Selected file contents are sent to GitHub when you initiate an upload
or sync.** Review the destination repository and its visibility before
uploading. If you upload content to a public repository, other people
may be able to view it.

### Local app data

GitSync may store app data on your device to support its features, such
as project details, file snapshots or sync information, recently
selected folders, and authentication state. Authentication tokens are
intended to be stored using Android's encrypted storage facilities. The
app may retain permission to access a folder you selected so you do not
need to select it again.

The precise information retained can vary with the app version and the
features you use.

### Technical and diagnostic information

Your device and Android system may process standard technical
information needed for app operation and network communication. GitHub
may also receive request and security information when GitSync
communicates with GitHub. This policy does not claim that GitSync
operates a separate analytics or crash-reporting service.

## 2. How Information Is Used

GitSync handles information to:

-   Authenticate your GitHub account through GitHub's authorization
    flow.
-   Show or work with repositories and repository details available to
    the app.
-   Create a repository when you request that action and the granted
    permissions allow it.
-   Read selected files and folders and upload their contents to the
    GitHub repository you choose.
-   Track local project and sync state so the app can provide its core
    functionality.
-   Maintain app security and troubleshoot operation where applicable.

GitSync should access selected files and perform GitHub actions only as
needed for the feature you invoke.

## 3. Where Information Goes

GitSync communicates with GitHub services to authenticate you and carry
out GitHub operations. Information you choose to upload---including file
contents and filenames---is transferred to GitHub and handled under
GitHub's terms and privacy practices.

GitSync is not GitHub and is not affiliated with or endorsed by GitHub.
Your use of GitHub is also subject to GitHub's policies.

**GitHub privacy information:**
https://docs.github.com/en/site-policy/privacy-policies/github-privacy-statement

## 4. Data Sharing

GitSync does not sell your personal information.

Information is shared with GitHub when necessary to authenticate your
account or complete an action you request, such as viewing repository
data, creating a repository, or uploading files. GitHub then processes
that information under its own policies.

Your chosen repository's visibility settings matter: content uploaded to
a public repository may be accessible to the public. GitSync cannot
control how GitHub or other users handle content after it has been
uploaded.

## 5. Storage, Security, and Retention

GitSync is designed to keep app-specific project information on your
device and to protect stored authentication tokens using Android
encrypted storage. No method of electronic storage or transmission is
completely secure, so absolute security cannot be guaranteed.

Local data may remain on your device until you remove it, clear the
app's data, uninstall the app, or use an applicable in-app removal or
disconnect feature. Disconnecting GitHub should remove the app's locally
stored authentication token; it does **not** delete repositories or
files already uploaded to GitHub.

Data already uploaded to GitHub is governed by GitHub's systems, your
repository settings, and any actions you take there. Deleting GitSync
does not automatically delete your GitHub repositories or uploaded
content.

## 6. Permissions

Depending on your Android version and app build, GitSync may use:

-   **Internet access** to communicate with GitHub.
-   **Network state access** to determine whether network connectivity
    is available.
-   **Android's system file/folder picker** so you can grant access to
    specific files or folders you choose.

GitSync is designed to use the Android file picker for user-selected
content rather than requesting unrestricted access to all files on your
device. Available permissions may differ by app version.

## 7. Your Choices

You can:

-   Choose which files and folders to select and which GitHub repository
    receives them.
-   Review repository visibility before uploading.
-   Revoke GitSync's authorization from your GitHub account settings.
-   Disconnect your GitHub account in GitSync, where that feature is
    available.
-   Remove local app data by clearing GitSync's storage or uninstalling
    the app.
-   Delete uploaded content or repositories through GitHub, subject to
    GitHub's available controls.

Revoking authorization prevents future GitHub API access using that
authorization, but it does not automatically remove content previously
uploaded to GitHub.

## 8. Children's Privacy

GitSync is not designed specifically for children. If you believe a
child has provided personal information to GitSync, contact us using the
email below so we can review the concern.

## 9. International Processing

GitSync may transfer information to GitHub, which may process it in
countries other than your own. The handling of information by GitHub is
subject to GitHub's policies and applicable terms.
